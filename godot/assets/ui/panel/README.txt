Panel baslik fotografi (gazete sablonu: solda buyuk baslik, sagda cerceveli fotograf). Dosyayi buraya at (png/jpg/webp), kodda degisiklik gerekmez.
Adlandirma (ilk bulunan kullanilir):
  Bina: <binanin_adi_slug>.png  (orn. sailors_bar.png)  ->  yoksa tur: esnaf, eglence, luks, atolye, depo, konut, resmi, ozel  ->  yoksa bina.png
  Bina adinda barber -> barber_shop; church/chapel/cathedral -> kilise.png, precinct -> polis.png, airport/airfield -> havaalani.png
  Bolge: bolge_<id>.png  ->  yoksa bolge.png
  Diger paneller: ben, aile, adamlar, grup, defter, garaj, polis, meslek, zafer, silah, yetenek .png
Gorsel yatay (3:2) kirpilir (ustten ~%30); renkli olabilir: oyun gri tona cevirip kagida sepya toner gibi basar.
Gorsel yoksa baslik fotografsiz cizilir.
